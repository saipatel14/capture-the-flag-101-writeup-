# Capture the Flag 101 – Writeup

🔗 Lab Reference: [Capture the Flag 101: Find and Submit Your First Flag](https://hackerdna.com/labs/learn-101)

## 🎯 Objective
Understand the basics of Capture the Flag (CTF) challenges and successfully locate and submit the first flag.

## 🛠 Tools & Techniques Used
- Web Browser Developer Tools (Inspect Element, View Source)
- Search functionality (`Ctrl+F` for keywords like `flag`)
- URL manipulation
- Optional: `curl` or `wget` for direct file access

## 🔎 Methodology
1. Explored the lab environment and layout.
2. Inspected the source code for hidden inputs, comments, or file references.
3. Located a clue pointing to a file path.
4. Accessed the file directly via URL.
5. Retrieved and submitted the flag (not disclosed here).

## 📚 Key Learnings
- Always check HTML source for hidden clues.
- Exposed files highlight why sensitive data should never be left accessible.
- Reinforced systematic exploration: observe → inspect → test → validate.

## ⚡ Challenges Faced
- Initially overlooked hidden comments in the source code.
- Learned to slow down and scan thoroughly.

## 🚀 Insights for Future Labs
- Build a checklist: source code, hidden inputs, robots.txt, JS variables, URL paths.
- Automate repetitive tasks with scripts.
- Document findings clearly for portfolio building.
